# Projeto Seletor de Personagens - One Piece

Aplicação web interativa inspirada no universo de One Piece. O projeto foi desenvolvido para consolidar conhecimentos práticos de manipulação do DOM e estilização, permitindo que o usuário alterne dinamicamente as imagens e descrições dos personagens ao clicar em seus respectivos ícones.

## 🚀 Sobre o Projeto
O objetivo principal foi criar uma interface dinâmica onde a seleção de um personagem altera em tempo real o conteúdo principal da tela. O projeto foca na experiência do usuário através de transições suaves e interatividade via código.

### Tecnologias e Conceitos
* **Linguagens:** HTML5, CSS3 e JavaScript.
* **Estruturas:** Manipulação de eventos, manipulação do DOM (Document Object Model), seletores de classe e estilização responsiva.
* **Ferramentas:** Git e GitHub para controle de versão.
